## 📖 Overview

This is the **SQL** learning path inside the **[DS-ML-COURSE](https://github.com/vinayakmishra4/DS-ML-COURSE)** repository — a self-paced journey from relational database theory through to writing scalable, production-ready queries. It's organized into five progressive modules, each with its own guides and hands-on practice scripts.

Whether it's brushing up on a basic `SELECT` or optimizing a slow query with indexes and partitioning, every stage of that journey is documented here.

## 🎯 Skills Gained

- 🏛️ **Database Theory** — keys, schema design, and core relational concepts
- ✏️ **Full CRUD Proficiency** — DDL & DML across `CREATE`, `INSERT`, `UPDATE`, `DELETE`
- 🔍 **Core Data Retrieval** — filtering, grouping, pattern matching, joins & subqueries
- 🪟 **Advanced Analytical Querying** — window functions, ranking, transactions & views
- 🧹 **Real-World Data Cleaning** — missing values, duplicates, outliers & date handling
- ⚡ **Performance Tuning** — CTEs, indexing, execution order & table partitioning
- 💼 **Applied Problem-Solving** — real business-style datasets and case studies throughout
