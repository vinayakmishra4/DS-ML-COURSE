# 📊 DAX — Data Analysis Expressions

> A practical guide to **DAX (Data Analysis Expressions)** for Power BI, Excel Power Pivot, and SQL Server Analysis Services.

---

## 🚀 Introduction

**DAX (Data Analysis Expressions)** is a powerful formula language used for data analysis, calculations, and business intelligence.

DAX is primarily used with:

- 📊 **Power BI**
- 📗 **Excel Power Pivot**
- 🗄️ **SQL Server Analysis Services (SSAS)**

It helps users create calculations, analyze data, build business metrics, and develop dynamic reports and dashboards.

---

## 🎯 What is DAX?

DAX is a collection of **functions, operators, and expressions** designed to work with tabular data models.

Using DAX, you can create:

- 🧮 Calculated Columns
- 📈 Measures
- 🗃️ Calculated Tables
- 📊 Business Metrics
- 📅 Time-Based Calculations
- 🔍 Advanced Data Analysis

DAX helps transform raw data into meaningful business insights.

# 🧩 Core DAX Concepts

## 1️⃣ Calculated Columns

A **calculated column** is a new column created within a table using a DAX expression.

Calculated columns are evaluated **row by row** and are useful when a value needs to be calculated for every record.

### Common Uses

- Discount calculations
- Profit calculations
- Product categorization
- Customer segmentation
- Data classification

---

## 2️⃣ Measures

A **measure** is a dynamic calculation primarily used in Power BI reports.

Measures are evaluated according to the **current filter context** and can respond to slicers, filters, report pages, and visual interactions.

### Common Measures

- Total Sales
- Total Profit
- Average Sales
- Profit Margin
- Sales Growth
- Year-to-Date Sales

> 💡 **Tip:** Measures are one of the most important concepts to master in DAX.

---

## 3️⃣ Calculated Tables

DAX can also be used to create **calculated tables** derived from existing data.

Common uses include:

- Summary tables
- Supporting tables
- Date-related tables
- Analytical tables
- Specialized data structures

# 🛠️ DAX Function Categories

## ➕ Aggregation Functions

Used to summarize numerical data.

Common functions include:

- `SUM`
- `AVERAGE`
- `MIN`
- `MAX`
- `COUNT`

## 🧠 Logical Functions

Used for conditional and logical calculations.

Common functions include:

- `IF`
- `AND`
- `OR`
- `SWITCH`

## 🔍 Filter Functions

Used to work with and modify filtering behavior.

Common functions include:

- `FILTER`
- `ALL`
- `ALLEXCEPT`
- `REMOVEFILTERS`

## 📅 Date & Time Intelligence

Used for calculations involving dates and time periods.

Common functions include:

- `TOTALYTD`
- `DATEADD`
- `SAMEPERIODLASTYEAR`
- `DATESYTD`

# 🧠 Understanding DAX Context

Understanding **context** is one of the most important parts of learning DAX.

### 🔹 Row Context

Row context refers to the **current row being evaluated**. It is particularly important when working with calculated columns.

### 🔹 Filter Context

Filter context refers to the **filters affecting a calculation**.

It can come from:

- Report filters
- Visual filters
- Slicers
- Rows and columns
- Relationships
- DAX expressions

Understanding both contexts is essential for writing effective DAX.

---

# ⭐ CALCULATE

`CALCULATE` is one of the **most important functions in DAX**.

It allows a calculation to be evaluated under a **modified filter context**.

Understanding `CALCULATE` is an important step toward writing advanced DAX calculations.

> 🚀 **Mastering CALCULATE is essential for advanced DAX.**
