## 📖 Overview

**Data Handling in Power BI** is a hands-on learning module covering the Power Query techniques used to get raw data into Power BI and shape it into something analysis-ready — importing and loading data, fixing data types, and replacing inconsistent values. Each concept is documented alongside a downloadable `.pbix` practice file.

This module sits inside the same broader personal learning repository, **[DS-ML-COURSE](https://github.com/vinayakmishra4/DS-ML-COURSE)**, alongside the **[SQL](https://github.com/vinayakmishra4/DS-ML-COURSE/tree/main/SQL)** learning path — together tracking an ongoing data science and machine learning journey.

## 🎯 Skills Gained

- 🔌 **Connecting Data Sources** — importing from files, databases, and cloud sources into Power BI
- 👀 **Interface Fluency** — navigating the Report, Data, and Model views
- 🧹 **Row & Column Cleanup** — removing blanks/duplicates, fixing headers, dropping unneeded columns
- 🔢 **Correct Data Typing** — assigning text, number, date, and boolean types accurately
- 🔄 **Value Standardization** — replacing inconsistent or incorrect entries with Replace Values
- 📝 **Change Tracking** — using Applied Steps to build a repeatable, auditable cleaning process
- 📊 **Analysis-Ready Data** — turning a raw import into a clean table ready for visuals
