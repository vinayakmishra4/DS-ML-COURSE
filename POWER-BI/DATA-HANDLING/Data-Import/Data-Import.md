## 📖 Introduction

Power BI allows you to connect to data from files, databases, cloud
services, and web sources. Importing data is the first step toward
creating reports and dashboards.

## 🎯 Learning Objectives

-   Import CSV files
-   Understand Report, Data, and Model views
-   Use Power Query Editor
-   Create your first visualization

## 📋 Prerequisites

-   Power BI Desktop
-   CSV or Excel dataset
-   Basic knowledge of tables

## 🌐 Supported Data Sources

  Category    Examples
  ----------- -------------------------------
  Files       CSV, Excel, JSON, XML
  Databases   SQL Server, MySQL, PostgreSQL
  Cloud       Azure, SharePoint

# 🚀 Step 1 -- Open Power BI Desktop

Launch Power BI Desktop.

# 📥 Step 2 -- Import Data

1.  Home → **Get Data**
2.  Select **CSV**
3.  Browse and select your file.
4.  Click **Load**.

# 👀 Step 3 -- Views

## 📊 Report View

Create charts and dashboards.

## 📄 Data View

Inspect table data.

## 🔗 Model View

Manage relationships.

# 🔄 Step 4 -- Power Query Editor

Open **Transform Data**.

Common tasks:

-   Rename columns
-   Remove duplicates
-   Change data types
-   Filter rows
-   Use First Row as Headers

Click **Close & Apply**.

# 📈 Step 5 -- Create Visuals

Choose a visual and drag fields onto it.

Popular visuals:

-   Card
-   Bar Chart
-   Column Chart
-   Line Chart
-   Pie Chart
-   Matrix

## 💡 Best Practices

-   Verify data types
-   Remove unnecessary columns
-   Check null values
-   Save frequently

## ⚠️ Common Mistakes

  Mistake           Solution
  ----------------- --------------------------
  Wrong data type   Change type
  Duplicate rows    Remove duplicates
  Missing headers   Use First Row as Headers

## 🛠 Troubleshooting

  Problem             Solution
  ------------------- --------------------------
  CSV won't load      Verify format
  Wrong headers       Use First Row as Headers
  Data not updating   Close & Apply

## ❓ Interview Questions

1.  What is Get Data?
2.  What is Power Query?
3.  Difference between Load and Transform Data?
4.  Explain Model View.
5.  Why are relationships important?

## 📝 Conclusion

Importing and preparing clean data is the foundation of every Power BI
project.
