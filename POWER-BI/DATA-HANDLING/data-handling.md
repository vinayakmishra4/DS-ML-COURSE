# 📖 What is Power BI?

> **Power BI** is Microsoft's **Business Intelligence (BI)** platform that converts raw data into meaningful, interactive, and visually appealing reports and dashboards.

Whether you're working with **Excel files, SQL databases, cloud platforms, or APIs**, Power BI allows you to analyze data and uncover valuable insights for better decision-making.

# 🚀 Step-by-Step Guide

## ① Download Power BI Desktop

⬇ Download from Microsoft

💻 Install on Windows

🚀 Launch the application

---

## ② Connect to Data

Click **Get Data**

Supported Sources:

- Excel
- SQL Server
- CSV
- Azure
- Web
- Oracle
- MySQL

---

## ③ Clean & Transform Data

Using **Power Query**

✔ Remove Duplicates

✔ Handle Missing Values

✔ Rename Columns

✔ Change Data Types

✔ Merge Tables

✔ Split Columns

---

## ④ Create Visualizations

Simply drag fields onto the report canvas.

Popular visuals include:

📊 Bar Chart

📈 Line Chart

🥧 Pie Chart

🗺 Map

📋 Matrix

📑 Table

🎯 KPI Card

🎛 Slicer

---

## ⑤ Build Interactive Dashboards

Combine multiple visuals into one dashboard.

Interactive Features:

- Filters
- Drill Through
- Tooltips
- Bookmarks
- Cross Filtering

---

## ⑥ Publish & Share

Publish reports to Power BI Service.

Share with:

👨‍💼 Teams

🏢 Organizations

📱 Mobile Users

🌍 Web
